How it works

図面を「読む」のではなく、理解してDXF化する

OCRで文字を取るだけでは、加工可能なCADにはなりません。幾何と寸法を結び、DXF要素として再構成します。

  1. 01

    PDF補正

    傾き・余白・ノイズを補正し、読み取りやすい図面に整えます。

  2. 02

    図形認識

    直線・円・円弧、穴や切欠きなど、外形を構成する要素を抽出します。

  3. 03

    寸法理解

    寸法文字と形状を紐付け、数値と幾何の対応を取ります。

  4. 04

    CAD再構成

    座標と輪郭を LINE / ARC / CIRCLE / POLYLINE のDXF要素へ変換します。

  5. 05

    人の確認

    低信頼箇所を色付きで示し、担当者はそこだけ確認・修正します。

新規図面も、設計変更も

一から作図する案件と、新旧を見比べる案件の、両方に対応します。

新規図面

ゼロからCADを起こす代わりに、AIがDXF初稿を生成。担当者は確認と修正へ進めます。

設計変更図面

旧図面と新図面を比較し、変更箇所と修正候補を提示します。寸法の書き換え作業を短縮します。

図面から現場、そして経営判断まで

DXF初稿が早く上がれば、CAM・加工・進捗の可視化まで一気に進めます。作図待ちでラインが止まる時間を、設計と現場の対話に変えます。

対応する図面と出力

入力

  • A4 PDFの2D平面図（1ファイルあたり1〜4頁）
  • 外形線と穴形状が明確な代表パターン
  • 新規図面、および設計変更の前後図面

出力

  • DXF（LINE / ARC / CIRCLE / POLYLINE）
  • 加工前のたたき台としてCADに読み込み可能な初稿
  • 低信頼箇所の色付き表示

現時点の対象外

  • 複雑な注記、低解像度、曖昧な箇所は要確認として表示します
  • 3Dソリッドや高度なアセンブリ表現は初期範囲外です

よくあるご質問

普通のOCRと何が違いますか？+

文字を読み取るだけでは、加工可能なCADにはなりません。立体OCRは外形・穴・寸法を理解し、LINE / ARC / CIRCLE / POLYLINE などのDXF要素として再構成します。

完全に自動でDXFが上がりますか？+

初期は完全自動化ではなく、AI初稿と人の確認を前提にしています。低信頼箇所を色付きで示すため、担当者はそこだけ確認すれば進められます。

どのような図面に対応しますか？+

A4 PDFの2D平面図（1ファイル1〜4頁）で、外形線と穴形状が明確な代表パターンを初期対象としています。複雑な注記や低解像度の箇所は要確認として表示します。

出力したDXFは、どのCADで開けますか？+

一般的なCADが読み込めるDXF（LINE / ARC / CIRCLE / POLYLINE）として出力します。ご利用中のCAD / CAM環境での読み込み確認は、導入時にご相談ください。

設計変更の図面にも使えますか？+

使えます。旧図面と新図面を比較し、変更箇所と修正候補を提示します。寸法を一から書き換える作業を減らすことが目的です。

FreeとBasicの違いは何ですか？+

Freeは月10枚までの変換で、まずは精度と修正量を確認いただくプランです。Basicは月額3,000円で、安定利用・優先処理・メールサポートが付きます。枚数や要件が大きな場合はEnterpriseをご検討ください。

サービス提供に必要な範囲でのみ取り扱います。追加学習に用いる場合は契約および事前同意の範囲に限り、他のお客さまのモデルへ無断転用はしません。詳しくはプライバシーポリシーをご覧ください。
